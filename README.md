# Microsoft Fabric ETL Pipeline

This project demonstrates an end-to-end data engineering pipeline for BuildMate Rentals, built on Microsoft Fabric using Medallion Architecture. The project ingests, transforms, validates, and serves rental data across Bronze, Silver, and Gold layers using Fabric Lakehouse, PySpark, and SQL.


## Architecture

```text
  Source Files
     │
     ▼
  Bronze Layer
     │
     ▼
  Silver Layer
     │
     ▼
   Gold Layer
     │
     ▼
    Power BI
```

## Data Processing Layers

### 1. Bronze Layer

The Bronze layer stores the **raw data** received from the source files.

- Stores raw rental data with minimal transformation.
- ingested_at and source file name columns are added.
- New data is loaded using **append mode**.
- Preserves historical source data.
- Acts as the starting point for downstream processing.

### 2. Silver Layer

The Silver layer contains **cleaned and validated rental data**.

- Reads data from the Bronze layer.
- Applies data quality and validation rules.
- Removes duplicate rental records.
- Uses the **latest-record rule** for deduplication.
- Separates invalid records into a **quarantine table**.
- Uses **overwrite mode** in the current implementation.
- The build is designed to be **idempotent**, so running it multiple times does not create duplicate records.

### 3. Gold Layer

The Gold layer contains **business-ready data** used for reporting and analysis.

- Uses cleaned data from the Silver layer.
- Applies business-level transformations and aggregations.
- Creates analytical tables required for reporting.
- Uses **overwrite mode** in the current implementation.
- Provides data that can be consumed by Power BI.

## Key Business Questions

- **Rental Duration:** Which asset types have the longest average rental duration?
- **Depot Utilisation:** Which depots have the highest fleet utilisation?
- **Revenue by Payer:** How is revenue split across different payer types?
- **Revenue by Depot:** How much revenue is generated by each depot, and what is the revenue per rental?
- **Rental Type Mix:** What percentage of total rentals belongs to each rental type?
- **Current Fleet Availability:** How many machines are currently out on rental at each depot?
